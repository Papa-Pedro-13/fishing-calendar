# Документация проекта «Календарь рыбалки» (Fishing Calendar)

Документация фиксирует **фактическое состояние кода** на 22.10.2026 и **системный анализ
для дальнейшего развития**. Проект — бэкенд на NestJS; сейчас реализован погодный слой
(нормализованный прогноз, кэш, валидация, тесты), предметная область и ИИ-рекомендации
ещё не написаны.

**Ключевая идея продукта:** рекомендации генерирует **ИИ-модель**, которой передаются все
факторы ловли (погода и почасовой прогноз, Луна, водоём, профиль вида, отчёты, правила,
снасти пользователя), а на выходе получается готовый **гайд на рыбалку** — окна активности,
снасть, поводок, наживка, прикормка, тактика и предупреждения. Оценку дня и юридические
ограничения считает детерминированный код, а не модель (см. [06](06-recommendations.md)).

## Краткий статус

**Готово:** погодный слой — проксирование WeatherAPI.com (текущая погода и прогноз),
нормализованная модель вместо сырого ответа провайдера, маппер, TTL-кэш с выдачей
устаревших данных при сбое, валидация `mode`/`days`/`date`, коды ошибок 400/429/502/503,
`/api/health`, `request-id` в логах, Swagger со схемой ответа, 27 unit + 18 e2e тестов.

**Не готово:** предметная область — БД, виды рыб и их повадки, водоёмы и точки, отчёты,
региональные правила, авторизация; **ИИ-рекомендации** (модуль, промпт, схема гайда,
guardrails); фронтенд; CI, Docker, починка конфига ESLint.

**Главные технические проблемы:** `npm run lint` падает из-за закомментированного плагина
prettier; нет CI и Dockerfile; кэш только in-memory и без фонового обновления; API не
версионирован. Подробно — в [04-implementation-status.md](04-implementation-status.md).
