# Документация проекта «Календарь рыбалки» (Fishing Calendar)

Документация описывает **фактическое состояние кода** на 22.10.2026 и **системный анализ
для дальнейшего развития**. Проект представляет собой бэкенд на NestJS, в котором на
данный момент реализован только один сценарий — получение прогноза погоды с фазой Луны.

## Краткий статус

**Готово:** модуль `weather` — проксирование WeatherAPI.com (текущая погода и прогноз до
14 дней) с добавлением фазы и возраста Луны через `lunarphase-js`. Swagger, CORS,
глобальный префикс `api`, Fastify-адаптер.

**Не готово:** предметная область календаря рыбалки целиком — база данных, виды рыб и их
повадки, локации/водоёмы, отчёты о рыбалке, алгоритм рекомендаций, сезонные и региональные
правила, авторизация, кэширование, фронтенд, тесты.

**Главные технические проблемы:** не подключён `ValidationPipe` (DTO не валидируются), файл
окружения `.env.local` не совпадает с ожидаемым `.env`, e2e-тест обращается к удалённому
эндпоинту `GET /`, ошибки провайдера теряют причину, отсутствуют кэш, логирование и тесты
погодного модуля. Подробно — в [04-implementation-status.md](04-implementation-status.md).
